健身记录助手 · 网页版部署说明
====================================

这份文件夹就是完整的网页版，不需要任何后端。
数据保存在手机浏览器里，不会上传到服务器（代码公开，数据不公开）。

--------------------------------------------------
方案一：GitHub Pages
--------------------------------------------------
【原理】把文件放进一个 GitHub 仓库，GitHub 帮你把它们当成静态网站发出来，
        自带 HTTPS，免费。

【前提】一个 GitHub 账号；仓库必须是 Public（免费账号的私有仓库不能开 Pages）。
        注意：公开的是**代码**，你的训练数据只存在手机浏览器里，不会进仓库。

1. 注册/登录 https://github.com
2. 右上角 + → New repository
   - Repository name: fitness-log
   - 选 Public
   - 勾选 Add a README file
   - Create repository
3. 进入仓库 → Add file → Upload files
   - 把本文件夹里的文件全部拖进去（index.html 必须在根目录，不能套文件夹）
   - 点 Commit changes
4. 仓库顶部 Settings → 左侧 Pages
   - Source: Deploy from a branch
   - Branch: main ／ 文件夹: / (root)
   - Save
5. 等 1-2 分钟，刷新 Settings → Pages，顶部会出现网址：
   https://你的用户名.github.io/fitness-log/
6. 手机 Chrome 打开该网址 → 菜单 →「添加到主屏幕」

【以后更新】仓库 → Add file → Upload files → 覆盖同名文件 → Commit，约 1 分钟生效。

--------------------------------------------------
方案二：Cloudflare Pages（拖拽更简单）
--------------------------------------------------
1. https://dash.cloudflare.com 注册
2. Workers & Pages → Create → Pages → Upload assets
3. 项目名随意 → 把文件拖进去 → Deploy
4. 得到 https://xxx.pages.dev

--------------------------------------------------
装好之后先确认三件事
--------------------------------------------------
1. 顶部显示「📱 数据存在这台设备」= 已脱离电脑独立运行
2. 随便记一条 → 保存 → 关掉浏览器重开 → 数据还在
3. 历史页点一次「备份 JSON」，发到微信收藏（数据只在这台手机，清浏览器会丢）

【常见问题】
- 打开是 404：检查 index.html 是否在仓库根目录、Pages 分支是否选对
- 页面空白：构建还没完成，等 1-2 分钟再刷新
- 手机装不上：要用 Chrome；国产浏览器可能没有"添加到主屏幕"
- 国内访问 github.io 偶尔慢：换手机网络重试，或改用 Cloudflare Pages
